# Online Examination System

A comprehensive, lightweight Online Examination System that manages online quizzes, examinations, automated grading, timer limits, and student results.

## Features
- **Student & Examiner Portals**: Role-based access control for students and test administrators.
- **Exam Management**: Create exams, configure question pools, passing marks, and time limits.
- **Automated Grading & Scoring**: Instant scoring and evaluation of multiple-choice and short-answer questions.
- **Security & Integrity**: Session token validation and tamper-proof grading records.
